صلاحيات سلم الضباط (LT - 1LT - Cpt - Maj)

  • إشراف على مسؤول الفترة والرقباء وإدارة القسم (إجباري).
  • إنذار: يحق للضباط استدعاء المحكمة ومحاسبة الفرد بما يراه مناسباً مع رفع تقرير للشؤون.
  • صرف نقاط (حد 15 نقطة) أسبوعياً مع رفع تقرير لإدارة الشرطة.
  • دخول كمواطن بدون طلب إذن.
  • صرف أي مركبة أو أي وينق في الميدان إلى حين تسجيل خروجك.
  • عمل تحديات ميدانية سواء داخل السيرفر أو رومات الديسكورد.
  • صلاحيات سلم الرقباء بشكل كامل.
  • صلاحيات اللبس الخاص ولكن: بشرط زي عسكري صحيح ويرمز إلى قطاعك.

صلاحيات سلم الرقباء (Sgt - 1Sgt - Ssgt)

  • إدارة الحالات (يطبق إجبارياً في أي وجود).
  • محاسبة الأفراد المخالفين ميدانياً | عقوبات عسكرية.
  • التوجيه العسكري الصحيح بدون عبارات سوقية.
  • في حال عسكري خالف يتوجه الرقيب لمكتب الشؤون بشكل مباشر.
  • استلام مسؤولية الفترة (إجباري).
  • في حال حاجة الميدان له (لن يستعلم فقط، Motorcycle أو AirShip صرف وتنسيق).
  • يحق لك إقامة صف دوام لجميع الوحدات المتواجدة في الميدان.
  • يحق لك مصادرة المركبات بالأيام (يومين كحد أقصى).

مفشلات الهروب الآمن (Safe Escape)

  • في حال نزول الشخص وبيده سلاح أو تم توجيه السلاح بشكل واضح.
  • تغيير المركبة.
  • يمنع خروج سيارات السوبر على الطرق السريعة وتعود للمفاوض لفرضها أو تركها.
  • تهديد حياة المواطنين أو الشرطي كـ عكس السير أو تصدميهم.
  • التوجه أو القرب إلى البحر.
  • القفزات بشكل عام.
  • الدخول إلى أماكن ضيقة أو الأنفاق.
  • دخولك إلى ورشة التصليح.
  • في حال السيارة كانت أوف رود يمنع صعود الجبال.
  • التدخل الخارجي.
  • الصعود على الأرصفة (الحد الأقصى 3 أرصفة).
  • العكسات (الحد الأقصى 3 عكسات).
  • في الهروب الشخص على الأقدام وبيده سلاح لمدة 5 ثواني يتم إطلاق النار على أطرافه بشكل متقطع.
  • الحد الأقصى للهروب: 10 دقائق.
  • إخراج سلاح بشكل واضح.

Codes العامة والعبارات الإنجليزية

  • Code 0: عموم الوحدات توجه للحالة (استنفار أمني).
  • Code 1: اغلق السير sirens والوانتات.
  • Code 2: اشغل السيراني فقط.
  • Code 3: اشغل السيراني والوانتات.
  • Code 4: المكان امن وخالي.
  • Code 6: مسح البصمات واخذ صور لموقع الجريمة.
  • Code 7: سحر او فلتش.
  • Shots fire: تبادل إطلاق نار.
  • Officer down: شرطي مسقط.
  • Dispatch Responding to: مركز العمليات استقبلت - متوجه إلى.
  • I Need Backup: احتاج دعم.
  • Pit Maneuver: صدمة احترافية.
